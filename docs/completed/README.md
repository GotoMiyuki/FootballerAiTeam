## 已接通的边界

A提供带context和版本的快照；B按固定输入与显式依赖执行，并核验专业成果、审查版本及正文发布条件；C持久化任务、输入与checkpoint。查看和解释使用原材料，暂停恢复使用原执行，关联新任务在提交时冻结最新球员状态与选定历史。

E记录有效建议与固定基线，读取时区分current、needs_reassessment、superseded、withdrawn；created不代表玩家选择或执行。E1.2分别记录采纳/拒绝/暂缓与用户自报执行，更正保留原关系，反馈不导入A事实。D通过独立受信服务将已有受审阅原生包导入A，不能把任意实时JSON直接当正式事件，也不会自动启动模型分析。验收actual根与当前应用配置分离。
