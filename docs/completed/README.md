## 已接通的应用流程

1. A 提供带生涯、分支、球员身份和来源版本的快照；任务提交时冻结输入。
2. B 根据固定输入和显式依赖执行，校验专业结果、审查版本及正文发布条件；输入变化沿依赖图撤销旧结果。
3. C 将任务、输入和 checkpoint 持久化。历史与解释使用原材料，暂停恢复使用原执行，新评估使用新身份和提交时最新快照。
4. E 从有效且可发布的训练成果保存建议，保留固定基线，并在读取时区分当前、待重评、已替代和已撤回。
5. D 已选定 PES2021/SP21 专用 BAL 的页面留证与人工核实方案；真实采集和向 A 导入尚未接通。

建议生成不会更新球员事实，created 事件不会代表玩家采纳或执行，demo 和模型替身不会被计为真实游戏闭环。
