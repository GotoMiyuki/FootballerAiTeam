## 维护规则

现行行为写在阶段汇总或操作指南，规划写在任务书和路线图，实验经过追加到对应合并日志的历史章节。历史结论不回写成当时就已成立的新结论；发现旧结论被后续验证替代，在现行章节说明，并保留原始记录。

新增引用优先使用相对链接和稳定章节锚点。移动、合并后运行 `python tools/check_docs.py` 检查本地文件与章节链接。检查不访问外网，也不把原始采集数据、游戏存档或知识库语料重新纳入Git；`docs/evidence/`下3份调查证据JSON保持原路径和原字节。
