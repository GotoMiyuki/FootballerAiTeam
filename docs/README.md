## 维护规则

按[文档管理规范](guides/文档管理规范.md)维护。现行操作写guide，规划写任务书/路线图，每轮开发过程使用新日志，实验/验收链接reports/completed。新记录不追加到preserved-source保留原文；历史结论不回写成当时就已成立的新结论。

新增引用优先使用相对链接和稳定章节锚点。`python tools/check_docs.py`检查本机全部文档；`--portable`检查Git内文档并单列[明确本机引用](local_references.json)，已接入独立Ubuntu/Windows文档CI。`python tools/check_version.py`核对VERSION与前端元数据；实际CI/发布结果见发布记录。检查不访问外网、不认证私有材料内容；原始采集、游戏存档、秘密配置与知识语料按既有策略保留，`docs/evidence/`下3份调查JSON保持原路径和原字节。
