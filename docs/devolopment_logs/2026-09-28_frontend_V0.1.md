# 前端 V0.1 开发记录

依据：`docs/FootballerAiTeam_Frontend_V0.1_开发指南.md`。

## 改动

新增 `frontend/`（React、TypeScript、Vite、TanStack Query、Tailwind）和 `backend/`（FastAPI、Public DTO、Mission Application Service、Event Adapter、SQLite persistence）。实现 Player/Mission 双工作区、计划与实时进度、Agent Activity、四种审查状态、人工输入、任务对话、历史恢复及 Markdown 报告查看/导出。

真实任务沿用现有 Agent Core。`graph.py` 只增加可注入 checkpointer 支持；默认行为保持 CLI 使用 MemorySaver。报告生成前保留原 CLI 的人工确认。

## 验证

- 原 LoopController 7 项回归通过。
- 新 Web 应用层 5 项测试通过；其中真实图接入使用确定性模型/工具节点、真实局部修订与 SQLite checkpoint，验证重启后输入续跑。
- 前端事件处理 5 项测试通过：去重、乱序、Mission 隔离、快照恢复、Plan 替换和无效 Envelope。
- TypeScript 与 Vite 生产构建通过；`npm audit` 为 0 漏洞。
- 浏览器实际验收一次通过、局部修订、重新规划、人工输入后续跑；检查刷新、追问、历史恢复、完整报告和 Markdown 下载。
- 本地 HTTP SSE 验证 `Last-Event-ID` 恢复，仅重放该 cursor 之后的事件。
- 真实模型/API smoke 完成任务：8 次 LLM 调用、2 次 Reviewer、1 次局部修订、0 次 Replan，总节点耗时约 97 秒；经过报告确认生成完整 Markdown 报告。测试使用隔离球员记忆副本，详细输出位于 Git 忽略的 `.web-test-data`。

## 运行和限制

见 `docs/Frontend_V0.1_运行与验收.md`。没有自动迁移旧 CLI 会话为 Web Mission；完成和 BLOCKED 任务支持跨服务重启恢复，执行中任务重启后保留快照并标为 FAILED。
